# ArrPilot

**A self-hosted media server controller**

ArrPilot is a fully featured, open source self-hosted controller focused on giving you a seamless experience between all of your self-hosted media software remotely on your devices.

> **This is a fork of [LunaSea](https://github.com/JagandeepBrar/LunaSea) (GPL-3.0)** which is no longer actively maintained. ArrPilot continues development with new features and improvements.

## Supported Services

ArrPilot currently supports:

- [Lidarr](https://github.com/lidarr/lidarr)
- [Radarr](https://github.com/radarr/radarr)
- [Sonarr](https://github.com/sonarr/sonarr)
- [NZBGet](https://github.com/nzbget/nzbget)
- [SABnzbd](https://github.com/sabnzbd/sabnzbd)
- [Newznab Indexer Searching](https://newznab.readthedocs.io/en/latest/misc/api/)
- [NZBHydra2](https://github.com/theotherp/nzbhydra2)
- [Tautulli](https://github.com/Tautulli/Tautulli)
- [Wake on LAN](https://en.wikipedia.org/wiki/Wake-on-LAN)

## Features

- **Webhook-based push notifications** - Stay informed about your media
- **Multiple profiles** - Manage multiple instances of each service
- **Backup & restore** - Protect your configuration
- **Dark themes** - Including AMOLED black theme
- **Cross-platform** - iOS, Android, macOS, Windows, Linux, Web
- **19 languages** - Multilingual support
- And much more!

> **Note:** ArrPilot is purely a remote control application. It does not offer any functionality without software installed on a server/computer.
